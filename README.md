- **Head Office**: SF No. 49 & 50, Bangalore–Chennai Highway, New Bypass Road, Vellore, Tamil Nadu – 632012, India
- **WhatsApp / Enquiry**: +91 93447 21689

## Tech Stack
- HTML5 (Semantic, SEO Optimized, Schema.org LocalBusiness JSON-LD)
- Vanilla CSS3 (Custom Design System, Modern Glassmorphism & Micro-interactions)
- Vanilla JavaScript (Touch-enabled Campaign Carousel, Real-time Form Validation & WhatsApp Integration)
- Vite (Ultra-fast build tooling)

## Getting Started

### Install Dependencies
```bash
npm install
```

### Run Locally (Dev Server)
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
Static production files will be output to the `dist/` directory.
